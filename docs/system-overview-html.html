Rob AI Studio je dogodkovno-zanjen (ledger-first) avtonomni stroj z dvema plastema: TS Hermes generira produkte iz navadne naloge, Python RSI/GStack avtonomno gradi in samozdravljenje module. Pod njima leži 18 podjetniških mikrostoritev.

01

Agenti in role
src/agents · čisti reduktorji

Agenti so čisti reduktorji: vhod RunState + Event, izhod Command[]. Nič I/O, ure ali okolja — vse zmožnosti (omrežje, disk, cmd.exec) so izključno v Runner. tests/agent-purity.test.ts to uveljavlja nad izvorno kodo.

Orkestrira jih core/orchestrator.py (RobAIOrchestrator._phase); poganjata ./rob build in POST /api/build. To je en vodilni agent (GSTACK-Architect), ne vzporedna jata.

04

Orkestracija
kdo kaj poganja

TS Hermes · produktni generator

Event-sourced zanka (Ledger → SQLite .gstack-run.sqlite). Stanje se izpelje iz dnevnika (foldState), nikoli iz mutirane spremenljivke. provenance() sledi vzročni verigi do artefakta.

  • vstop: bun run src/index.ts ali POST /api/run
  • ustavitev: run.complete/stuck · stepBudget · noProgressN · maxEventsPerRun
  • idempotenca: UNIQUE (run_id, idem_key) → replay = 0 klicev
  • varnost: cmd.exec allowlist + execCwdRoot
Python RSI/GStack · build modula

Zaprta samozdravitvena zanka. Dashboard in CLI delita isto jedro (run_swarm.py → orchestrator → gbrain → graphify → gstack → hermes → loopx).

  • vstop: ./rob build ali POST /api/build
  • verifikacija: pytest → 100% zelen ali FAILED (brez rollback-a)
  • trajni spomin: GBRAIN blacklisti + črne liste
  • LLM: DeepSeek (deepseek-chat), retry + fallback
